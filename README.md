# Woki — descargas

Woki es una app de finanzas personales de **SOULESS**. Este repositorio contiene **solo los instaladores**; el código fuente es privado.

## Windows

**[Descargar Woki para Windows](https://github.com/slzzth/woki-descargas/releases/latest/download/Woki-instalador.exe)**

- Durante la beta privada necesitas un código de invitación.
- El instalador aún no tiene firma digital: si Windows avisa, toca **Más información → Ejecutar de todas formas**.
- La huella SHA-256 de cada versión está en sus [notas de versión](https://github.com/slzzth/woki-descargas/releases).

## Teléfono y web

Abre https://woki-eight.vercel.app y, desde el menú, toca **Instalar en el teléfono**.
